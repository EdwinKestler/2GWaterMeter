the 8 s window
Commands only land while the radio is up

Commands and fingerprints arrive during the listen window alone. Keep fp retained on the broker so a device that missed a window still gets the current coefficients on its next connect.

lab broker
Point at the LAN IP, not localhost

Lab MQTT user and pass are both waterbox. Set mqttServer to the LAN address of the Compose host — the meter is not on that host.

Lab clock

This Core+ runs at 8 MHz — the actual UART came out at half of 57600 when the firmware was built as 16 MHz. PlatformIO board is 644pa8m; upload and serial are both 57600.
