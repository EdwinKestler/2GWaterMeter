2. Database flow

Postgres 16 schema · init.sql
Worker writes; Grafana reads

Write path (ingest)

A. Parse MQTT JSONimei from topic waterbox/<IMEI>/data|info
↓
B. UPSERT meterslast_seen, ppl, valve, fp_valid
↓
C. Lookup latest fingerprints rowpredict W(hour-of-day) → wm_cloud
↓
D. INSERT readingsts, lm, mls, tl_ml, v, wm, wm_cloud, lk, oc, raw jsonb

Tables

meters imei PK
  • first_seen / last_seen
  • pulses_per_liter
  • valve
  • fp_valid
readings id PK · imei FK
  • ts (device RTC)
  • lm / mls / tl_ml
  • wm (onboard W(t))
  • wm_cloud (Python W(t))
  • lk · oc · raw
fingerprints id PK · imei FK
  • w a1 p1 t1
  • a2 p2 t2
  • n_samples
  • published bool
meters.imei 1—* readings.imei  ·  meters.imei 1—* fingerprints.imei

Fit path (hourly)

  • SELECT readings for each imei where ts ≥ now − 14 d and lm IS NOT NULL
  • Need ≥ 24 samples (FIT_MIN_SAMPLES)
  • INSERT fingerprints with fitted coefficients
  • UPDATE meters.fp_valid = true
  • After MQTT publish: published = true

Read path (Grafana)

  • Variable $imei from SELECT imei FROM meters
  • Time series: lm, wm, wm_cloud vs ts
  • Stats: MAX(lk), MAX(oc), last tl_ml
  • Table: last 20 fingerprint rows
  • Indexes: (imei, ts DESC), partial lk=1 / oc=1
