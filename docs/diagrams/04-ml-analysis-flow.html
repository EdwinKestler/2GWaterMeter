4. Python analysis / fingerprint flow

software/waterbox_cloud/fingerprint.py
Cloud fits · device only evaluates
W(t) = w̄ + A₁ sin(2π t / T₁ + φ₁) + A₂ sin(2π t / T₂ + φ₂)    T₁ = 24 h   T₂ = 12 h   t = hour of day

1. Assemble samples

  • Every FIT_EVERY_SECONDS (3600)
  • Last 14 days of readings.lm
  • Hour-of-day in America/Guatemala
  • Skip IMEI if n < 24
→

2. Linear least squares

  • Expand sines: A sin(ωt+φ) = B sin ωt + C cos ωt
  • Design matrix: [1, sin ω₁t, cos ω₁t, sin ω₂t, cos ω₂t]
  • Solve 5×5 normal equations
  • A = hypot(B,C)   φ = atan2(C,B)
→

3. Publish fingerprint

  • INSERT fingerprints (w,a1,p1,a2,p2,t1,t2)
  • MQTT retain to …/fp
  • Device EEPROM stores params
